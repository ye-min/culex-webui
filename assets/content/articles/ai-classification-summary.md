# 人工智能全维度分类总结

---

## 一、AI 的技术范式（最顶层划分）

```
人工智能（AI）
│
├── ── 技术底座范式 ──────────────────────────────────
│
├── 机器学习（Machine Learning）       ← 当前主流技术底座
│   └── 从数据中自动学习规律（统计学习框架）
│       内含连接主义（Connectionism）的现代延伸：
│       └── 连接主义：模拟生物神经元网络实现智能
│           → 深度学习 / 神经网络是其现代实现形式
│
├── 符号主义 AI（Symbolic AI）         ← 经典技术底座
│   └── 基于规则、逻辑、知识的推理
│
├── 神经符号 AI（Neuro-symbolic AI）   ← 连接主义与符号主义的融合
│   └── 结合神经网络（连接主义）与逻辑推理（符号主义）
│
└── ── 应用/形态范式（底层依赖机器学习）────────────────
    │   注：以下两者属于系统级应用形态，
    │       而非与机器学习平行的技术底座范式
    │
    ├── 世界模型（World Models）
    │   └── 让模型建立对环境的内部表征与预测能力
    │       代表架构：JEPA（LeCun）、Dreamer
    │       → 具身智能和新一代生成式 AI 的核心组件
    │
    └── 具身智能（Embodied AI）
        └── AI 与物理世界交互，感知-决策-行动闭环
            代表方向：Figure、OpenAI Robotics、Google DeepMind
```

> **层级说明**：机器学习、符号主义 AI、神经符号 AI 是**技术底座范式**，描述 AI 实现智能的底层方法论。世界模型与具身智能是**应用/形态范式**，底层仍重度依赖深度学习与强化学习，建立在技术底座之上而非与之并列。

> **AI 三大宗派**：学术界公认 AI 有三大哲学宗派——**符号主义**（逻辑与规则）、**连接主义**（神经元网络）、**行为主义**（感知-动作控制论，不依赖静态知识，通过与环境的动态交互演化智能）。强化学习在哲学根源上是连接主义与行为主义的交叉产物：它用神经网络（连接主义）学习策略，用环境交互反馈（行为主义）驱动演化。具身智能的"动作-反馈"闭环和 DeepSeek-R1 的纯 RL 零阶段训练，均植根于行为主义这一底层范式。

> **连接主义与机器学习的关系**：连接主义（Connectionism）是 AI 的一种哲学路径，主张通过模拟生物神经元的大规模并行连接来实现智能；机器学习是更宽泛的统计学习方法论框架（包含决策树、SVM 等非神经网络方法）。深度学习是连接主义的现代实现形式，同时也属于机器学习的子集。神经符号 AI 因此更精确地定义为"连接主义与符号主义的融合"。

## 二、符号主义 AI 的子集

```
符号主义 AI
│
├── 专家系统（Expert Systems）
│   └── 用"如果…则…"规则库模拟专家推理
│
├── 知识表示与推理（Knowledge Representation & Reasoning）
│   ├── 知识图谱
│   ├── 本体论（Ontology）
│   └── 一阶逻辑
│
├── 自动规划（Automated Planning）
│   └── 制定行动序列达成目标
│
└── 搜索（Search）                        ← 搜索是跨范式的通用工具
    ├── 启发式搜索（A*、Dijkstra）        ← 经典符号主义代表
    └── 蒙特卡洛树搜索（MCTS）           ← 跨范式：起源于传统搜索，
                                             现已与深度学习/强化学习深度融合
                                            （AlphaGo、o1 推理时计算）
```

> **注**：搜索算法本身是连接符号主义、连接主义与传统算法的交汇工具，不应简单归入任何单一范式。A* 在纯符号系统中使用，但 MCTS 在现代 AI 中已成为跨范式的推理搜索组件。

## 三、机器学习：按学习方法分类

```
机器学习（按学习方法）
│
├── 监督学习（有标签数据）
│   ├── 分类
│   │   ├── 逻辑回归
│   │   ├── K近邻（KNN）
│   │   ├── 支持向量机（SVM）
│   │   ├── 朴素贝叶斯
│   │   ├── 决策树
│   │   └── 集成学习
│   │       ├── 随机森林
│   │       ├── XGBoost
│   │       └── LightGBM
│   └── 回归
│       ├── 线性回归
│       ├── 岭回归 / Lasso
│       └── 回归树
│
├── 无监督学习（无标签、无任何监督信号）
│   ├── 聚类
│   │   ├── K-means
│   │   ├── DBSCAN
│   │   └── 层次聚类
│   ├── 降维
│   │   ├── PCA
│   │   ├── t-SNE
│   │   └── UMAP
│   └── 异常检测
│       ├── 孤立森林（Isolation Forest）
│       └── One-Class SVM
│
├── 自监督学习（Self-Supervised Learning）  ← 近五年 AI 爆发的核心基石
│   ├── 从数据自身构造代理任务，学习通用表示，无需人工标注
│   ├── 对比式（Contrastive SSL）           ← 学习样本间相似/相异关系
│   │   ├── SimCLR / MoCo
│   │   └── CLIP（图文对比）
│   ├── 生成式（Generative SSL）            ← 重建/预测数据本身
│   │   ├── 掩码语言模型（MLM）：BERT
│   │   ├── 下一个词预测（CLM）：GPT 系列预训练
│   │   └── 掩码自编码器（MAE）：图像自监督
│   └── 非对比式（Non-contrastive / Joint Embedding）
│       ← 无需负样本，学习联合嵌入空间
│       └── VICReg、Barlow Twins、BYOL
│
├── 半监督学习（少量标签 + 大量无标签数据）
│   ├── 伪标签（Pseudo-labeling）
│   ├── 一致性正则化
│   └── 标签传播（Label Propagation）
│
└── 强化学习（交互奖惩反馈）
    ├── 基于价值
    │   ├── Q-learning
    │   └── DQN
    ├── 基于策略
    │   └── 策略梯度（Policy Gradient）
    └── 演员-评论家（Actor-Critic）
        ├── A3C
        └── PPO
```

> **自监督 vs 无监督**：两者均不需要人工标注，但自监督从数据内部构造代理监督信号（如预测被遮盖的词），无监督则完全不使用任何监督信号。大模型预训练属于自监督学习。

## 四、机器学习：按技术实现分类

```
机器学习（按技术实现）
│
├── 传统机器学习
│   ├── 线性模型                          [监督]
│   │   ├── 线性回归
│   │   ├── 逻辑回归
│   │   └── 岭回归 / Lasso
│   │
│   ├── 基于实例（KNN）                   [监督]
│   │
│   ├── 概率模型 / 信息论模型             [监督/无监督]
│   │   ├── 朴素贝叶斯                    [监督]
│   │   ├── 最大熵模型（MaxEnt）          [监督]  ← 早期 NLP 核心
│   │   │   注：多分类 MaxEnt 等价于 Softmax 回归（多分类逻辑回归），
│   │   │       是同一监督分类模型的不同表述，不具备无监督属性
│   │   ├── 贝叶斯网络                    [监督/无监督]
│   │   └── 高斯混合模型（GMM）           [无监督]
│   │
│   ├── 支持向量机（SVM）                 [监督]
│   │
│   ├── 决策树                            [监督]
│   │   ├── CART
│   │   └── ID3 / C4.5
│   │
│   ├── 集成学习                          [监督为主]
│   │   ├── Bagging（并行集成）
│   │   │   └── 随机森林
│   │   ├── Boosting（串行集成）
│   │   │   ├── AdaBoost
│   │   │   ├── XGBoost
│   │   │   └── LightGBM
│   │   └── Stacking（模型融合）
│   │
│   ├── 聚类                              [无监督]
│   │   └── K-means / DBSCAN / 层次聚类
│   │
│   ├── 降维                              [无监督]
│   │   └── PCA / t-SNE / UMAP
│   │
│   └── 异常检测                          [无监督为主]
│       └── 孤立森林 / One-Class SVM
│
└── 深度学习（神经网络）
    │
    ├── 判别模型（Discriminative Models）
    │   ├── 前馈神经网络（FNN）            [监督]
    │   ├── 卷积神经网络（CNN）            [监督为主]
    │   │   └── ResNet / VGG / EfficientNet
    │   ├── 循环神经网络（RNN）            [监督为主]
    │   │   └── LSTM / GRU
    │   ├── Transformer（判别方向）        [监督/自监督]
    │   │   ├── BERT（编码器）
    │   │   └── Vision Transformer（ViT）
    │   └── 图神经网络（GNN）              [监督/无监督]
    │       └── GCN / GAT
    │
    ├── 生成模型（Generative Models）
    │   ← 独立统计大类，与判别模型正交
    │   ← 学习概率密度分布并生成新样本（Generative Learning）
    │   ← 可采用无监督、自监督或监督方式训练，不归属单一学习范式
    │   │
    │   ├── 自回归模型（Autoregressive）
    │   │   ← 训练方式：自监督（CLM）
    │   │   ├── GPT 系列 / LLaMA
    │   │   └── 图像自回归（LlamaGen 等）
    │   ├── 变分自编码器（VAE）
    │   │   ← 训练方式：无监督（ELBO 变分推断）
    │   ├── 生成对抗网络（GAN）
    │   │   ← 训练方式：对抗训练（真/假标签由模型自动构造）
    │   │   ├── StyleGAN
    │   │   └── CycleGAN（循环一致性约束）
    │   ├── 扩散模型 / 基于得分的生成模型
    │   │   ← 两条路径由连续 SDE 框架统一（宋飏，2021）
    │   │   ← 路径一：扩散概率模型（DDPM）——加噪/去噪过程
    │   │   ← 路径二：得分匹配模型（Score Matching）——学习数据分布梯度
    │   │   ← 统称：Score-based Generative Models
    │   │          / Diffusion Probabilistic Models
    │   │   ├── DDPM（经典扩散）
    │   │   ├── Stable Diffusion
    │   │   └── DiT（Diffusion Transformer）← 当前主流架构
    │   │       └── FLUX 明确采用；Sora 具体架构 OpenAI 未公开
    │   └── 流模型族（Flow-based Models）
    │       ├── 规范化流（Normalizing Flow）
    │       │   ← 训练方式：最大似然估计（严格可逆变换）
    │       │   ← 局限：雅可比矩阵必须可逆且高效计算
    │       └── 流匹配（Flow Matching）/ 有向流（Rectified Flow）
    │           ← 对 Normalizing Flow 的突破性演进
    │           ← 通过 ODE 拟合任意概率路径，无需严格可逆约束
    │           ← 路径更直、采样更快，当前工业落地最广
    │           └── SD3、FLUX.1 底层；Sora 具体架构未公开
    │
    └── 深度强化学习                       [强化]
        ├── DQN / PPO
        └── AlphaGo / AlphaZero
```

> **生成模型定性说明**：生成模型（GAN、VAE、Diffusion、自回归）是与判别模型正交的独立统计学大类，核心目标是学习数据的概率密度分布（Generative Learning），不同于自监督学习以构造代理任务学习通用表示（Representation Learning）为目标。各子类的训练方式已在树中单独标注，不再统一打自监督/无监督标签。

> **PINN 层级说明**：物理信息神经网络（PINN）按损失函数构造分类，与判别/生成模型按建模目标分类标准不一致，不宜并列。PINN 作为"深度学习与科学计算的交叉特例"，详见第六节 AI for Science。

> **两个维度的关系**：学习方法描述"学什么"，技术实现描述"怎么学"，二者正交可交叉组合。

## 五、大模型（LLM）的训练范式

```
大模型训练（以 GPT、Claude、DeepSeek 为例）
│
├── 第一阶段：预训练                           [自监督学习]
│   └── 海量无标签文本，预测下一个词（CLM）
│       技术：Transformer 解码器架构
│
├── 第二阶段：监督微调（SFT）                  [监督学习]
│   └── 人工标注的高质量对话数据，学习指令遵循
│
├── 第三阶段：偏好对齐
│   ├── RLHF（人类反馈强化学习）               ← 经典方案
│   │   ├── 训练奖励模型（RM）
│   │   └── PPO 优化策略（需 Critic 网络）
│   ├── RLAIF（AI 反馈强化学习）               ← 规模化替代人工标注
│   │   ├── Constitutional AI（Anthropic）
│   │   └── UltraFeedback 等
│   ├── RFT（拒绝采样微调）                    ← SFT 与 RL 之间的过渡技术
│   │   └── 用模型自身采样的高质量输出做 SFT，成本低于完整 RL
│   ├── DPO（直接偏好优化）                    ← 无需奖励模型，适合垂直微调
│   ├── Iterative DPO（迭代式 DPO）            ← 解决 DPO 静态数据缺陷
│   │   └── 迭代更新偏好数据，缓解似然性偏移问题
│   ├── RLOO（Reinforce Leave-One-Out）         ← 免 Critic 的 RL 方案
│   │   └── 与 GRPO 平行竞争：同样无需 Critic，用留一法消除基线偏置
│   │       注：RLOO 沿用 REINFORCE 框架，GRPO 做组内优势归一化，二者非前后辈
│   ├── GRPO（群体相对策略优化）               ← 推理模型对齐主流
│   │   ├── 核心价值：取消 Critic 网络
│   │   │   对同一提示词生成一组输出，计算组内相对奖励
│   │   │   → 显著降低显存开销，适合超大规模推理训练
│   │   └── 代表：DeepSeek-R1，开源社区大规模采用
│   └── ORPO / SimPO 等                        ← 更新的简化对齐方案
│
└── 第四阶段：推理时计算（Inference-time Compute）  ← 2024-2026 新范式
    ├── 提示词级 / 激活级推理（Prompt-level）
    │   └── 思维链（Chain-of-Thought, CoT）
    │       → 改变输入格式，不改变模型结构
    │       → 激活模型已有的推理能力
    │
    └── 搜索级 / 算法级推理（Search-level）    ← 真正的范式跃迁（System 2）
        ├── ── 端到端模型内生路线（主流）────────────────────
        │   ├── MCTS 引导的推理搜索
        │   ├── 过程奖励模型（PRM）引导的最佳优先搜索 / Rollout
        │   │   注：Beam Search 缺乏回溯机制，不适合长文本复杂推理
        │   │       最佳优先搜索（Best-First Search）为当前主流
        │   └── 自我纠错（Self-Correction）
        │       ← 既是搜索训练后的涌现能力，也是可被 RL 显式优化的训练目标
        ├── ── 外部框架控制路线（早期探索）──────────────────
        │   ├── Self-Consistency（多数投票）← 采样多个答案取多数
        │   └── ToT / GoT（思维树/图）← 外部控制推理路径
        │       注：随 o1/R1 端到端路线成熟，此路线已逐步边缘化
        └── 代表模型：OpenAI o1/o3、Claude 3.7 Sonnet Thinking、
                       DeepSeek-R1
```

> **阶段说明**：预训练为自监督学习（非无监督）。偏好对齐已从单一 RLHF 演进为多路线并行：RLAIF 解决人工标注规模瓶颈，DPO 简化训练流程适合垂直微调，GRPO 通过免 Critic 架构专为超大规模推理训练优化。推理时计算代表大模型从"训练时扩展"转向"推理时扩展"的新范式。

> **推理时计算的两个层级**：CoT 属于提示词级推理，通过改变输入激活模型已有能力，成本低但天花板有限。MCTS、PRM 引导的最佳优先搜索属于搜索级推理（System 2 推理），是真正的算法级范式跃迁；Beam Search 因缺乏回溯机制不适合此场景。

> **DPO vs RLHF 的扩展边界**：DPO 开发成本低，适合垂直领域微调和中小规模对齐。但在超大规模复杂推理对齐中，DPO 的损失函数只约束相对似然比，缺乏像 PPO 那样的绝对奖励锚定，当模型对某错误 token 的似然度极高时，可通过压低其他 token 概率来满足损失函数——即丧失对无偏分布的锚定，导致**策略退化/泛化性丧失（Policy Degradation / Likelihood Drift）**。复杂推理任务上 GRPO、PPO 仍是主流。

> **数据扩展的结构性瓶颈**：互联网高质量公开文本数据的规模存在上限，大模型规模扩展正逐步转向：①**合成数据（Synthetic Data）**——由强模型生成训练数据自我蒸馏；②**推理时扩展**——在固定参数下通过更多计算换取更高质量输出。

> **AI 安全对齐（补充维度）**：2026 年大模型深水区落地中，安全对齐已成为独立技术维度，主要包括：**红队测试（Red Teaming）**——主动发现模型漏洞；**越狱防御（Jailbreak Defense）**——抵御对抗性提示；**机器遗忘（Machine Unlearning）**——选择性删除有害知识；**可解释性（Interpretability）**——理解模型内部决策机制。

## 六、AI 的应用领域分类

```
AI 应用领域
│
├── 计算机视觉（CV）
│   ├── 图像分类 / 目标检测 / 图像分割
│   ├── 人脸识别
│   └── 图像生成
```

## 七、AI 的数学基础

```
AI 数学基础
│
├── 线性代数                              ← 核心基础
│   ├── 矩阵运算（神经网络前向传播）
│   ├── 特征值/特征向量（PCA）
│   └── 向量空间（词向量、嵌入）
│
├── 概率与统计                            ← 核心基础
│   ├── 概率分布（贝叶斯、高斯）
│   ├── 最大似然估计
│   └── 信息论（交叉熵损失、KL 散度）
│
├── 微积分与优化                          ← 核心基础
│   ├── 梯度下降
│   ├── 反向传播
│   └── 凸优化
│
├── 离散数学                              ← 核心基础
│   ├── 图论（图神经网络）
│   └── 逻辑（符号主义 AI）
│
├── 随机微积分（Stochastic Calculus）     ← 进阶，扩散模型数学基础
│   ├── 随机微分方程（SDE）
│   │   └── 扩散模型（Score Matching）的理论基础
│   └── Itô 积分
│
├── 泛函分析 / 变分法                     ← 进阶，强化学习与扩散模型基础
│   ├── 变分法（策略梯度收敛性的底层工具）
│   ├── 泛函空间（连续 SDE、无限维优化）
│   └── 逆强化学习（IRL）的理论支撑
│
├── 数值分析                              ← 工程数学方向
│   ├── 混合精度（FP16/BF16/FP8）误差分析
│   ├── 量化误差与精度损失
│   ├── 算子融合与数值稳定性
│   └── 分布式并行通信优化（3D 并行：PP/TP/DP）
│       └── 流水线排布与同步误差分析
│
└── 几何学 / 拓扑学                       ← 前沿研究方向
    ├── 流形学习（数据低维结构的几何理解）
    ├── 几何深度学习（图、群、流形上的神经网络）
    └── 拓扑数据分析（TDA）
```

> **层级说明**：线性代数、概率统计、微积分、离散数学是从业必备核心基础。随机微积分和泛函分析是理解扩散模型与强化学习理论的进阶基础。数值分析属于工程数学方向，对大模型训练工程实现（量化、混合精度）不可或缺但非理论研究必须。几何/拓扑属于前沿研究方向。

## 九、核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| 监督学习 | 有标签数据，学输入到输出的映射 |
| 无监督学习 | 无标签、无监督信号，自动发现数据结构 |
| 自监督学习 | 从数据自身构造代理任务，学习通用表示，无需人工标注 |
| 半监督学习 | 少量标签 + 大量无标签数据结合训练 |
| 强化学习 | 与环境交互，通过奖惩学习策略 |
| 深度学习 | 多层神经网络，自动学习特征；连接主义的现代实现形式 |
| 行为主义 | AI 三大宗派之一；通过感知-动作控制论与环境动态交互演化智能；强化学习和具身智能的哲学根源 |
| 连接主义 | 通过模拟生物神经元大规模并行连接实现智能的哲学路径；深度学习的思想根源 |
| 判别模型 | 学习条件概率 P(y\|x)，用于分类/回归 |
| 生成模型 | 学习数据概率密度分布 P(x)，能生成新样本；独立统计大类，不归属单一学习范式 |
| 世界模型 | 建立对环境内部表征的模型；分数据驱动的通用视觉世界模型（如 Sora）和动作驱动的具身控制世界模型（如 Dreamer）两类；JEPA 是预测编码架构，是世界模型的一种实现路径 |
| 物理世界模型 | 动作驱动的具身控制专用世界模型，强调对牛顿力学、碰撞、摩擦等物理规律的精确反演 |
| 具身智能 | AI 与物理世界交互的系统级形态，感知-决策-行动闭环；底层依赖机器学习 |
| VLA | 视觉-语言-动作模型，多模态向物理世界延伸的关键桥梁，实现端到端操控 |
| 空间智能 | 对三维空间结构的理解与推理能力，机器人导航与操控的核心 |
| 迁移学习 | 把一个任务学到的知识用到另一个任务 |
| 注意力机制（Attention） | Transformer 的核心组件，通过计算 Query-Key-Value 的相关性实现上下文感知 |
| 大模型（LLM） | 超大规模 Transformer，具备通用能力 |
| 困惑度（PPL） | 衡量语言模型预测能力的核心指标，PPL 越低表示模型对文本的预测越准确 |
| RLHF | 用人类偏好反馈训练奖励模型，再用 RL 对齐 |
| RLAIF | 用 AI 反馈替代人工标注，规模化对齐方案（如 Constitutional AI） |
| RFT | 拒绝采样微调，用模型自身高质量采样做 SFT，是 SFT 与完整 RL 之间的过渡技术 |
| DPO | 直接优化偏好，无需奖励模型；损失函数只约束相对似然比、缺乏绝对奖励锚定，复杂推理中易导致策略退化/Likelihood Drift |
| Iterative DPO | 迭代式 DPO，通过动态更新偏好数据缓解静态 DPO 的似然性偏移问题 |
| RLOO | Reinforce Leave-One-Out；与 GRPO 平行竞争，均为免 Critic 方案；RLOO 用留一法消偏置，GRPO 做组内优势归一化，二者非前后辈关系 |
| GRPO | 群体相对策略优化；免 Critic 网络，通过组内相对奖励显著降低显存开销；DeepSeek-R1 核心 |
| DiT | 基于 Transformer 的扩散模型架构；FLUX、SD3 等明确采用；Sora 具体架构 OpenAI 未公开 |
| 推理时计算 | 推理阶段扩展计算量；分提示词级（CoT）和搜索级（MCTS/PRM）两个层次 |
| 自我纠错 | 推理模型动态调整思考路径的能力；既是搜索级训练后的涌现表现，也是可被 RL 显式优化的训练目标 |
| PINN | 物理信息神经网络，将物理方程嵌入损失函数，AI for Science 核心技术 |
| Score-based 生成模型 | 扩散概率模型与得分匹配模型通过 SDE 框架统一后的学术统称 |
| 流匹配（Flow Matching） | 通过 ODE 直接拟合概率流的生成模型新范式；路径更直、采样更快；SD3、FLUX.1 的底层技术 |
| 最大熵模型（MaxEnt） | 信息论驱动的概率分类模型；多分类形式在数学上等价于 Softmax 回归（多分类逻辑回归） |
| 合成数据 | 由强模型生成训练数据，应对高质量公开数据规模上限的核心策略 |
| 过拟合 | 模型过度学习训练数据的噪声和特性，导致泛化能力下降 |
| 欠拟合 | 模型容量不足，未能捕捉数据的底层真实分布与规律 |
| 梯度下降 | 沿损失函数梯度方向更新参数 |
| 反向传播 | 计算梯度的算法，深度学习的核心 |
| 泛函分析/变分法 | 理解策略梯度收敛性与连续 SDE 的底层数学工具 |
| AI for Science | 将 AI 用于科学发现，包括蛋白质预测、物理模拟、数学证明等 |
| 红队测试（Red Teaming） | 主动攻击模型寻找安全漏洞，AI 安全对齐的核心工程手段 |
| 越狱（Jailbreak） | 通过对抗性提示绕过模型安全限制；越狱防御是大模型落地的关键技术挑战 |
| 机器遗忘（Machine Unlearning） | 选择性删除模型中特定有害知识或隐私数据，无需完整重训练 |
| 可解释性（Interpretability） | 理解模型内部决策机制；Anthropic 的机制可解释性（Mechanistic Interpretability）是当前前沿方向 |
